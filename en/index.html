G3MM4

Educational game with a local language model · Unity 6 · 2026

Role

Developer: model integration and inference architecture

A cyberpunk detective RPG for Spanish speakers learning English. Character interrogations, a translation minigame and the detective's narration are generated by a language model that returns typed JSON output.

I designed a common inference interface with swappable engines: Gemma running locally through Ollama in the editor, MediaPipe to run it on the Android phone itself, and a stub engine. When the model breaks the schema, a parser with three retries recovers the response. Prompts are templates the design team can edit, and text streams in.

Tasks for people and agents

MCP server · Firebase · 2026

Role

Author

A task manager on Firestore shared in real time by people and AI agents. I wrote its MCP server in TypeScript, with ten tools to list, create, comment, split into steps and check activity, plus a log of which agent made each change. Claude Code, a phone agent and other assistants use it every day.

Cost-aware model orchestration

Agent tooling · 2026

Role

Author

A toolkit that routes work across several models by cost: my own MCP server that delegates mechanical tasks to Gemini Flash, registered in Claude Code, OpenCode and Codex; scripts that measure each provider's remaining quota; and Amazon Bedrock access through boto3 to run Claude and Qwen3 Coder on credits.

Claude Code hooks and skills remind agents to delegate. I measured before deciding: on the same coding challenges, Gemini Flash used about 0% of the quota versus 30% for a large model.

A 27-billion-parameter model on two GPUs

Local inference · August 2026

Role

Author

I served Qwen 27B locally with llama.cpp, split across an RTX 5070 and an RTX 3070, and exposed it to agents as an MCP tool. The split took it from 2.6 tokens per second on a single card to 25.5.

I retired it after comparing it with cloud models: with an 8,192-token context and lower accuracy on game engine code, delegating was the better choice.

Tech

llama.cppQwenCUDAMCP
